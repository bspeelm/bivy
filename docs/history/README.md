# History

Retired documents, kept verbatim rather than deleted.

A plan that has shipped, or a document whose content has moved somewhere
else, is retired here. It is not maintained and is not held to the present:
the budgets skip this directory when counting live prose, and the conformance
check skips it when grepping, because an append-only record cannot be fixed.

Read something here as an answer to "what was the reasoning at the time", never
as a description of how the program works now. `PLAN.md` and
`docs/decisions.md` are the current answers to that.
